Repositorio de la actividad integradora de gráficas TC2008B ad24.  
Este proyecto implementa un juego inspirado en Galaga en un entorno 3D utilizando Unity.

---

## Descripción

El juego está basado en la dinámica clásica de los *space shooters*:
- El jugador controla una nave.
- Debe esquivar ataques enemigos.
- Debe disparar para eliminar enemigos y sobrevivir.

El objetivo es aplicar conceptos de programación y gráficas en tiempo real dentro de Unity.

---

## Características

- Control del jugador (nave)
- Sistema de disparos
- Enemigos y patrones de aparición
- Colisiones y lógica de daño
- Sistema de juego (vidas, derrota o puntaje)
- Efectos visuales mediante shaders

---

## Tecnologías

- Unity 3D
- C#
- ShaderLab
- HLSL

---

## Estructura del proyecto

- `Assets/`  
  Contiene scripts, escenas, materiales, prefabs, shaders y recursos del juego.

- `ProjectSettings/`  
  Configuración global del proyecto en Unity.

- `Packages/`  
  Paquetes y dependencias administradas por Unity.

---

## Ejecución local

1. Clonar repositorio:
   ```bash
   git clone https://github.com/NicoH00d/ActividadIntegradora-Graficas.git
   ```

2. Abrir Unity Hub.

3. Seleccionar **Open** y elegir la carpeta del proyecto.

4. Abrir la escena principal del juego.

5. Ejecutar con **Play** dentro del editor.
